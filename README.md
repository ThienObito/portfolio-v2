# portfolio-v2

Personal portfolio — scroll-driven storytelling site built with Next.js.

## Run

```bash
npm install
npm run dev       # localhost:3000
npm run build     # static export → ./out
```

## Stack

- Next.js 14 (App Router)
- React 18
- TypeScript
- Tailwind CSS
- Canvas API (scroll-driven sequence)

Deploys to Vercel, Netlify, or any static host.
